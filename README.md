# bilinote

把 B 站视频转成**带时间戳的 Markdown 笔记**。

优先用视频自带的字幕轨（秒出）；没有字幕、或字幕不可信时，回退到本地 faster-whisper 转写。全程不调用大模型，纯本地跑，免费。

## 它做什么

输入一个 BV 号或视频链接，输出一份 `.md`：

- 标题、UP 主、时长、来源链接
- 抽取式要点（按词频打分，不调模型）
- 按停顿断句、合并成段、**每段带时间戳**的正文

适合：看长视频前先扫一眼结构、把讲座/纪录片存成可检索的文字、做读书笔记式的资料整理。

## 安装

```bash
pip install requests faster-whisper
```

（`faster-whisper` 只在需要本地转写时用；第一次跑会自动下模型。）

## 用法

```bash
python bilinote.py BV1xxxxxxxxx
python bilinote.py https://www.bilibili.com/video/BV1xxxxxxxxx
```

可选：

```bash
python bilinote.py BV1xxxx -o out.md      # 指定输出文件
python bilinote.py BV1xxxx --no-asr       # 只用字幕，没字幕就报错
```

## 踩过的三个坑（都写进代码了）

1. **有字幕轨 ≠ 有内容**：有些视频的字幕整轨是 `♪音乐♪` 占位行。会让它按实词比例判断，不够就回退转写。
2. **字幕时间戳可能超出视频时长**：接口偶尔返回别的视频的字幕（3 分半的视频给出 7 分钟内容）。加了时长校验，越界即判无效。
3. **时长合法也可能是错的内容**：字幕整段属于另一个视频，时间戳都在片长内。目前仍在补第三道护栏（标题词需出现在正文里）。

> 教训：接口"有数据"不等于"数据对"。

## 已知限制

- 需要联网取 B 站接口（字幕、元信息）
- 本地转写的准确度取决于模型大小与音质
- 弹幕、评论、画面内容都不处理
